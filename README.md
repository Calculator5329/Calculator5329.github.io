# Ethan Gates Portfolio

Public portfolio and resume site for Ethan Gates, positioned as an AI-native
software engineer building production AI products, agent systems, and
data-intensive full-stack applications.

The React site presents a short recruiter path through a profile, selected
project evidence, technical stack, education, certifications, and resume.
Portfolio priorities and claims are governed by the parent
[`career` roadmap](../docs/roadmap.md); the implementation queue lives in
[`docs/roadmap.md`](docs/roadmap.md).

## Local verification

```sh
npm install
npm run build
```

`npm run build` is the non-deploy verification command. Publication uses the
separate `npm run deploy` script and remains owner-only.
